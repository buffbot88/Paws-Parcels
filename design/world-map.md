# Paws & Parcels — World Map Reference (current)

> **Current hub:** `zone-clover-village` (`src/data/maps/clover-village.json` — generated by
> `scripts/generate-clover-village.mjs`, seed 7, deterministic). The retired single-player
> tile sketches (Post Office, Bramble Patch, and the earlier ~29-wide plaza layout) were
> removed — this document now describes only the **shipped 75×75 layout**.
> Spawn/monster rules for the online game: [`BuildPlan.md`](../BuildPlan.md) §8,
> [`monsters.md`](monsters.md). NPC cards: [`npcs.md`](npcs.md).
> Where each zone's clearings, thickets and framed entrances belong is authored separately, in
> `src/data/maps/<zone>.composition.json` (see `design/decisions.md`, *Composition intent lives
> in per-zone JSON*); it is decoration only and never changes collision or the map itself.

## Zone: Clover Village (hub) — `zone-clover-village`

Dimensions: **75×75 tiles**. Tile size **48×48**; every zone shares one world-camera zoom
(`WORLD_CAMERA_ZOOM = 1.1` in `src/scenes/OverworldScene.ts`, visual Pass 1), which shows
≈18×10 tiles at the 960×540 reference resolution, and one framing rule: the camera focus
sits 9% of the viewport height above the courier so the world ahead gets more of the frame
(`src/game/cameraFraming.ts`, see `design/decisions.md`). Regenerate with `node scripts/generate-clover-village.mjs`
(self-checks walkability + landmark reachability before writing); migration
`013_clover_village_new_layout.sql` resets existing village couriers to the new plaza.

- **Courier Square plaza** at `(37,28)`, spawn `(37,31)` — paved cobble ring with a
  flower-front central bed
- **Two-story Post Office** (Building 17) north — footprint x33–41 / y15–22
- **Café** (Building 16) west · **Research Shop** (Building 5) east ·
  **Florist** (Building 3) southeast
- **Fenced open Moss garden** x40–52 / y40–47 (no building)
- Two background cottages (with clotheslines), NW pond + **Rabbit Burrow** landmark,
  SW **Hollow Oak** clearing (`object-hollow-oak` — Golden Acorn quest), SE pond +
  picnic clearing, lamp-lined southern road through the **entrance arch**
- Southern transition to Happy Valley at **`(37,74)`** (banner gate)

### Art passes (client)
- `src/game/cloverVillageAssets.ts` depth-sorts ~150 set pieces against couriers via
  `worldDepth` (shadow + art per piece); placements in `cloverVillagePlacements.ts`
- Ground tiles are procedurally textured (`TileTextures.ts`) — meadow, road, plaza
  cobble; props come from the CloverValley pack plus five procedurally authored cutouts
  (café tables, garden beds, clotheslines, entrance arch, lily pads)
- Collision stays authoritative in the ASCII map; every set piece is visual-only
- Parity harness: `tests/data/interactable-art-parity.test.ts` guarantees every
  interactable has adjacent dedicated art

## Zone: Happy Valley (outdoor) — `zone-happy-valley`

**40×26** open-world monster map (Phase 3), entered from the village's south edge —
valley entrance at `(20,0)`, village gate at `(37,74)`. Mossy Pond, blueberry patch,
southern transition back to Clover Village.

- Set pieces come exclusively from the valley's own pack
  (`reference/assets/maps/HappyValley/Map/PNG`); placements in
  `src/game/happyValleyPlacements.ts`, glue in `happyValleyAssets.ts`
- Ground: authored meadow + path textures via `generateValleyMeadow()` /
  `generateValleyPath()` (`scripts/generate-ground-assets.mjs`)
- Art parity: `tests/data/happy-valley-art-parity.test.ts`
- Monster family + spawn rules: [`monsters.md`](monsters.md)

## Content placement rules
- Gathering nodes regrow daily (respawn on new in-game day)
- NPCs never move between zones in MVP; dialogue changes with friendship level
- Lost-item spawn locations for errand quests live in `src/data/quests.json`
  (`findAt` per quest); they spawn only while the quest is active and despawn on
  completion

## Friendship quest rewards (L4 Best Friend)

spawns (no `requiredItemId`/`findAt`; completed on first interaction with the giver
after friendship level 4):
