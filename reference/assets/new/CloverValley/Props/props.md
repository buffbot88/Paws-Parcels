Village bench — simple woodland wooden bench for Courier Square and social areas.
Village lamp post / route lantern — outdoor path lighting, designed as a standalone map prop rather than another hanging building lantern.
Small wooden footbridge — for pond/wetland crossings and later maps; useful for making routes visually interesting even if the collision remains simple.
Fence set — straight section, corner, end post, and small gate. This will help define Maple’s flower area, Moss’s garden, cottages, and route edges without invisible-looking boundaries.
Pond/wetland cluster — reeds, cattails, lily pads, small stones and maybe a log. The existing terrain has water, but the shoreline needs recognizable dressing.
Rabbit Burrow landmark — a proper visible quest landmark rather than something that reads like a generic marker.
Picnic setup — blanket/basket/food cluster. Biscuit and Maple already have picnic-related content, so this can become both scenery and a quest destination.
Quest-item sprites — polished pebble, letter opener, Lumi’s notebook, Golden Acorn. These should be small standalone assets so a “search” quest can eventually show the actual recovered object rather than only firing an interaction.
Route clutter variations — smaller parcel bundle, mail sack, single crate, tied box, maybe courier satchel. The big parcel cluster is good for the Post Office, but smaller pieces would let us scatter the delivery theme without cloning the same large graphic everywhere.
